# Reference samples

This directory is reserved for local, authorized black-box reference samples from Luminar Neo and matching zpixel_edit outputs.

Each case should contain:

```text
case-001/
  input.jpg
  parameters.json
  material-id.txt
  luminar-output.png
  zpixel-output.png
  comparison.json
```

Do not commit copyrighted or private reference images without authorization. The current repository contains the directory contract only; no reference output is claimed yet.
